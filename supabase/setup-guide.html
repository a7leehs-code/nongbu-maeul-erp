전자결재 · 실사용 연결

직원들이 각자 폰으로 결재하게 만들기

대표님이 직접 하실 일은 ①~③, 약 15분입니다. ④는 클로드에게 맡기면 됩니다.
① Supabase 가입 · 프로젝트 만들기 — 5분
  1. supabase.com 에 들어가 가입합니다 (GitHub 계정으로 가입하면 편합니다).
  2. New project → 이름 nongbu-erp, 지역은 Northeast Asia (Seoul).
  3. 데이터베이스 비밀번호는 따로 적어두세요. 클로드에게 알려줄 필요는 없습니다.
② DB 설정 붙여넣기 — 3분
  1. 이 폴더의 supabase/approvals.sql 을 메모장으로 엽니다 → 전체 선택 → 복사.
  2. Supabase 왼쪽 메뉴 SQL Editor → 새 쿼리 → 붙여넣기 → Run.
  3. 「Success」가 뜨면, 같은 방법으로 supabase/talk.sql(마을톡)도 실행합니다. 순서는 approvals → talk 입니다.
  4. 여러 번 실행해도 괜찮습니다.
💡 (선택) 직원들이 가입할 때 확인 메일 없이 바로 쓰게 하려면: Authentication → Sign In / Providers → Email 에서 「Confirm email」을 끕니다. 켜두면 가입 후 메일의 링크를 한 번 눌러야 합니다.
③ 주소와 공개 키 가져오기 — 2분
  1. Project Settings → API (또는 Data API) 로 갑니다.
  2. Project URL 과 anon · public 키 두 개를 복사해 클로드에게 주세요.
⚠ service_role 키(또는 secret 키)는 절대 붙여넣지 마세요. 모든 권한을 가진 열쇠라 공개되면 안 됩니다. anon 키는 공개돼도 괜찮습니다 — 누가 무엇을 볼 수 있는지는 ②에서 넣은 DB 규칙이 지킵니다.
④ 연결 · 첫 가입 — 클로드와 함께
  1. 클로드가 erp-config.js 에 두 값을 넣습니다. 전자결재 화면 위쪽이 초록색 「실사용 모드」로 바뀝니다.
  2. 대표님이 제일 먼저 「처음 가입」 하세요. 맨 처음 가입한 사람이 대표가 됩니다.
  3. GitHub에 올리면(클로드에게 "올려줘") 직원들이 폰에서 이 주소로 들어옵니다:
    https://a7leehs-code.github.io/nongbu-maeul-erp/erp-approvals.html
  4. 직원이 가입하면 대표 화면 「직원 관리」에 뜹니다 → 「사용 허용」을 눌러야 결재를 쓸 수 있습니다.
✅ 이렇게 되면 성공: 직원 폰에서 올린 문서가 대표 폰의 「내 차례」에 뜨고, 직원 화면에는 승인 버튼이 아예 없으며, 억지로 요청해도 서버가 「대표만 승인할 수 있습니다」로 막습니다.
